=============================================
  ИНСТРУКЦИЯ ПО НАСТРОЙКЕ МЕНЮ ВЫБОРА ПЕРСОНАЖА
=============================================

Этот пакет добавляет меню с выбором из двух персонажей:
- SCP-106 (с телепортацией)
- Человек (обычный персонаж)

---------------------------------------------
ШАГ 1: Настройка сцен в Build Settings
---------------------------------------------

1. Откройте File > Build Settings
2. Добавьте две сцены (перетащите из Project):
   - Слот 0: ваша сцена меню (например "Menu")
   - Слот 1: ваша игровая сцена (например "Game")

---------------------------------------------
ШАГ 2: Настройка сцены МЕНЮ
---------------------------------------------

1. Создайте новую сцену или откройте существующую для меню
2. Создайте пустой GameObject (GameObject > Create Empty)
3. Назовите его "MenuManager"
4. Перетащите скрипт MainMenu.cs на этот объект
5. В инспекторе укажите имя игровой сцены в поле "Game Scene Name"
   (по умолчанию "Game" - должно совпадать с именем сцены в Build Settings)
6. Готово! Меню создается автоматически при запуске

---------------------------------------------
ШАГ 3: Настройка ИГРОВОЙ сцены
---------------------------------------------

1. Откройте вашу игровую сцену
2. Убедитесь что у объекта игрока стоит тег "Player":
   - Выберите объект игрока
   - В инспекторе вверху найдите "Tag"
   - Выберите "Player"
3. Создайте пустой GameObject и назовите его "GameManager"
4. Перетащите скрипт GameManager.cs на этот объект
5. Готово!

---------------------------------------------
ГОТОВО! Проверка:
---------------------------------------------

1. Нажмите Play в сцене меню
2. Должно появиться меню с двумя кнопками
3. Нажмите "SCP-106" - загрузится игра с телепортацией
4. Или нажмите "Человек" - загрузится обычная игра

---------------------------------------------
УПРАВЛЕНИЕ ТЕЛЕПОРТАЦИЕЙ (SCP-106):
---------------------------------------------

- Зажмите ЛКМ: появится маркер-сфера куда вы целитесь
- Отпустите ЛКМ: телепортация к маркеру
- Перезарядка: 3 секунды (настраивается)
- Максимальная дальность: 15 юнитов (настраивается)

Цвета маркера:
- Синий: прицеливание
- Зеленый: можно телепортироваться
- Красный: перезарядка

---------------------------------------------
СОСТАВ ФАЙЛОВ:
---------------------------------------------

- MainMenu.cs      - скрипт главного меню (создает UI автоматически)
- SCPTeleport.cs   - способность телепортации для SCP
- GameManager.cs   - менеджер выбора персонажа
- README_MENU.txt  - этот файл с инструкцией

---------------------------------------------
ДОПОЛНИТЕЛЬНЫЕ НАСТРОЙКИ:
---------------------------------------------

MainMenu.cs (в инспекторе):
- Game Scene Name: имя игровой сцены
- Background Color: цвет фона
- Button Color SCP: цвет кнопки SCP
- Button Color Human: цвет кнопки Человека

SCPTeleport.cs (в инспекторе, если добавлен вручную):
- Max Distance: максимальная дальность телепорта
- Cooldown: время перезарядки
- Ground Layer: слой земли для рейкаста
- Teleport Height Offset: высота над землей при телепорте
- Marker Size: размер маркера
- Цвета маркера для разных состояний

GameManager.cs (в инспекторе):
- Player Tag: тег игрока (по умолчанию "Player")
- Debug Mode: выводить информацию в консоль

---------------------------------------------
ПРИМЕЧАНИЯ:
---------------------------------------------

- Скрипты работают с Unity 2021.3 и выше
- Телепортация работает с ЛЮБЫМ контроллером движения
  (CharacterController, Rigidbody, или просто Transform)
- MainMenu создает Canvas программно, ничего настраивать в UI не нужно
- Все скрипты полностью автономные, не зависят друг от друга
  (кроме GameManager который добавляет SCPTeleport)
