# Teleport Game - Unity Project

Игра с персонажем, обладающим способностью телепортации и спринта.

## Требования

- Unity 2021.3 LTS или новее (рекомендуется Unity 2022.3+)
- TextMeshPro (устанавливается автоматически через Package Manager)

## Быстрая настройка

### Вариант 1: Автоматическая настройка сцены

1. Откройте Unity и создайте новый 3D проект
2. Скопируйте папку `Assets/` в ваш проект
3. Создайте новую пустую сцену
4. Создайте пустой GameObject и добавьте на него компонент `GameSetup`
5. Запустите сцену - все объекты будут созданы автоматически

### Вариант 2: Ручная настройка

1. Создайте 3D проект в Unity
2. Скопируйте все файлы из `Assets/` в папку Assets вашего проекта
3. Создайте объект Plane (GameObject > 3D Object > Plane) - это будет земля
4. Создайте Capsule (GameObject > 3D Object > Capsule) - это игрок
5. Добавьте на игрока компоненты:
   - `CharacterController`
   - `PlayerController`
   - `TeleportAbility`
   - `SprintAbility`
   - `TeleportEffect`
   - `SprintEffect`
   - `TeleportRadiusIndicator`
6. Настройте камеру: добавьте `CameraFollow` на Main Camera
7. Создайте Canvas и добавьте `CooldownUI`

## Управление

| Клавиша | Действие |
|---------|----------|
| W/A/S/D | Движение персонажа |
| Зажать ЛКМ | Показать радиус телепортации и превью позиции |
| Отпустить ЛКМ | Телепортироваться в указанную точку |
| Left Shift (зажать) | Активировать спринт (макс. 10 секунд) |
| Отпустить Shift | Деактивировать спринт |

## Параметры для настройки

### PlayerController
- `Walk Speed` - базовая скорость ходьбы (по умолчанию: 5)
- `Gravity` - сила гравитации (по умолчанию: -20)

### TeleportAbility
- `Max Teleport Radius` - максимальный радиус телепортации (по умолчанию: 10 юнитов)
- `Cooldown Duration` - время перезарядки (по умолчанию: 2 секунды)
- `Ground Layer Mask` - слой земли для рейкаста

### SprintAbility
- `Sprint Duration` - максимальная длительность спринта (по умолчанию: 10 секунд)
- `Sprint Cooldown` - перезарядка после спринта (по умолчанию: 5 секунд)
- `Speed Multiplier` - множитель скорости (по умолчанию: 2x)

### CameraFollow
- `Offset` - смещение камеры от игрока
- `Smooth Speed` - скорость сглаживания
- `Normal FOV / Sprint FOV` - поле зрения камеры

## Описание скриптов

| Скрипт | Описание |
|--------|----------|
| `PlayerController.cs` | Основной контроллер: движение WASD, гравитация, интеграция способностей |
| `TeleportAbility.cs` | Система телепортации: прицеливание ЛКМ, ограничение радиуса, перезарядка |
| `SprintAbility.cs` | Система спринта: активация Shift, ограничение по времени, перезарядка |
| `TeleportEffect.cs` | Эффекты телепорта: частицы при уходе/приходе, вспышка, след |
| `SprintEffect.cs` | Эффекты спринта: линии скорости, трейл, пыль, изменение FOV |
| `TeleportRadiusIndicator.cs` | Визуальный круг радиуса телепорта на земле |
| `CameraFollow.cs` | Камера третьего лица с плавным слежением |
| `CooldownUI.cs` | HUD: индикаторы перезарядки телепорта и спринта |
| `GameSetup.cs` | Автоматическая настройка сцены (земля, игрок, свет, UI) |
| `TeleportCircle.shader` | Шейдер анимированного круга телепортации |

## Визуальные эффекты

### Телепортация
- Голубой полупрозрачный круг радиуса на земле (пульсирует)
- Призрачное превью персонажа в точке приземления
- Взрыв частиц в точке отправления (голубые)
- Взрыв частиц в точке прибытия (светло-голубые)
- Кратковременная вспышка экрана
- Световой след между точками

### Спринт
- Линии скорости (частицы вытянутые назад)
- Трейл за персонажем
- Увеличение FOV камеры (60 -> 75)
- Частицы пыли из-под ног

## Известные ограничения

- Материалы (.mat) нужно создать в Unity Editor (файлы .meta содержат настройки для справки)
- Для корректной работы рейкаста телепорта, земля должна иметь коллайдер и быть в правильном слое
- TextMeshPro должен быть импортирован в проект (Unity предложит это автоматически)
