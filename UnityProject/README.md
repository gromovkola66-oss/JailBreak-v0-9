# JailBreak - Unity Build

## Step 1: FPS Controller

### How to install:

1. Copy the `Assets/Scripts/` folder into your Unity project's `Assets/` folder
2. In Unity, click menu: **JailBreak > Setup Player (Step 1)**
3. Press **Play** to test

### Controls:
- WASD - Move
- Mouse - Look around
- Space - Jump
- Shift - Sprint
- C or Ctrl - Crouch
- Esc - Free cursor
